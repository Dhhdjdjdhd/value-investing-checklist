## 1단계. 사업의 질

- [x] 이 회사가 무엇으로 돈을 버는지 한 문단으로 설명할 수 있다 ✅
  - 설명: 검색·유튜브에서 전 세계 이용자의 관심을 모아 경매 방식으로 광고를 판다(매출의 약 3/4). 여기에 클라우드(AI 인프라 임대·기업용 소프트웨어)와 구독(유튜브 프리미엄, 워크스페이스)이 빠르게 크는 중. 이용자가 모일수록 데이터가 쌓여 광고·AI가 좋아지고, 그래서 이용자가 더 모이는 자기강화 구조.
- [x] 10년 뒤에도 이 제품/서비스가 필요할 것이다 ✅ ("정보를 찾고, 영상을 보고, 연산을 빌리는" 수요 자체는 소멸 불가)
- [x] 경제적 해자가 있다 ✅
  - [x] 브랜드 파워 ("구글링"이 동사)
  - [ ] 전환 비용 (소비자 쪽은 약함 — 광고주·클라우드 쪽은 있음)
  - [x] 네트워크 효과 (유튜브 크리에이터↔시청자↔광고주, 안드로이드 개발자↔사용자)
  - [x] 원가 우위 / 규모의 경제 (자체 TPU 칩 + 세계 최대급 데이터센터 → AI 연산 원가)
  - [x] 무형자산 (20년치 검색·행동 데이터)
  - 해자 근거: 검색 점유율 약 90%가 25년간 유지 — 마이크로소프트가 수백억 달러를 쓰고도 못 뺏은 자리
- [x] 가격 결정력이 있다 ✅ (광고는 경매 구조라 수요 증가 = 단가 상승. 유튜브 프리미엄·클라우드 인상에도 이탈 미미)
- [ ] 사업 모델이 단순하고 예측 가능하다 ⚠️
  - 구조: 복합기업처럼 보이나 매출 약 3/4이 광고 단일 엔진, Other Bets는 매출 1% 미만 — **구조는 단순한 편**
  - ⚠️의 원인은 구조가 아니라 **예측 가능성**: AI 검색 전환기 — 챗봇형 검색의 광고 모델 잠식 가능성 (2026 2Q 검색 +17%로 아직 데이터상 잠식 없음)
  - 구조·예측가능성을 별개 ⚠️ 2개로 세지 않은 이유: 우려의 실체가 AI 전환 하나이기 때문. 2개로 세면 1단계도 조건부 통과가 되나, 실질 판정(확신도 "보통" 상한)은 어차피 동일.
