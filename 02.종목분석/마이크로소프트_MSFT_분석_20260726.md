**2단계 DCF** — 앞으로 벌어들일 이익을 지금 가치로 바꿔 더한 값이 내재가치다.

미래의 돈은 지금 돈보다 가치가 낮다(지금 받으면 굴릴 수 있으므로). 그래서 **깎아서(할인해서)** 더한다.

- `현재가치 = 미래 금액 ÷ (1 + 할인율)^연차`
- `내재가치 = [1~10년 EPS의 현재가치 합] + [10년 뒤 주식가치의 현재가치]`

**기본 시나리오 실제 계산** — 기준 EPS $17.60 · 성장 +12%(1~5년) / +7%(6~10년) · 할인율 9.0% · 종료 PER 15.8배(역산으로 채운 값)

| 연차 | 그해 EPS | ÷ 할인계수 | = 현재가치 |
|---|---|---|---|
| 1년차 | $19.71 | ÷ 1.090 | $18.08 |
| 5년차 | $31.02 | ÷ 1.539 | $20.16 |
| 10년차 | $43.50 | ÷ 2.367 | $18.38 |
| … | (2~4, 6~9년차 생략) | | |
| **1~10년 합계** | | | **$191** |
| **터미널** (10년차 EPS $43.50 × 15.8배 = $687) | | ÷ 2.367 | **$290** |
| **내재가치** | | | **$481** |

**터미널이 내재가치의 60%를 차지한다.** 앞 10년을 아무리 정교하게 계산해도, 실제로 값을 좌우하는 것은
**"10년 뒤에도 이 회사가 건재한가"** 라는 가정이다.
→ 그래서 **1단계(사업의 질)에서 ❌면 그 시점에서 분석을 중단**한다. 그 질문에 답할 수 없으면
내재가치의 60%가 근거를 잃기 때문이다. **4단계는 1단계 위에 서 있다.**

**용어** — **EPS**: 주당순이익, 1주가 1년에 벌어다 주는 돈 · **PER**: 주가÷EPS, 1년 이익의 몇 배 가격인가 ·
**할인율**: 미래 이익을 깎는 비율(높을수록 보수적) · **종료 PER**: 10년 뒤 이 주식이 받을 것으로 보는 PER
