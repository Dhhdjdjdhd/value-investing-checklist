**2단계 DCF** — 앞으로 벌어들일 이익을 지금 가치로 바꿔 더한 값이 내재가치다.

미래의 돈은 지금 돈보다 가치가 낮다(지금 받으면 굴릴 수 있으므로). 그래서 **깎아서(할인해서)** 더한다.

- `현재가치 = 미래 금액 ÷ (1 + 할인율)^연차`
- `내재가치 = [1~10년 EPS의 현재가치 합] + [10년 뒤 주식가치의 현재가치]`

**기본 시나리오 실제 계산** — 기준 EPS $12.50 · 성장 +9%(1~5년) / +5%(6~10년) · 할인율 9.0% · 종료 PER 16배(표에 기재된 값)

| 연차 | 그해 EPS | ÷ 할인계수 | = 현재가치 |
|---|---|---|---|
| 1년차 | $13.63 | ÷ 1.090 | $12.50 |
| 5년차 | $19.23 | ÷ 1.539 | $12.50 |
| 10년차 | $24.55 | ÷ 2.367 | $10.37 |
| … | (2~4, 6~9년차 생략) | | |
| **1~10년 합계** | | | **$118** |
| **터미널** (10년차 EPS $24.55 × 16배 = $393) | | ÷ 2.367 | **$166** |
| **내재가치** | | | **$284** |

**터미널이 내재가치의 58%를 차지한다.** 앞 10년을 아무리 정교하게 계산해도, 실제로 값을 좌우하는 것은
**"10년 뒤에도 이 회사가 건재한가"** 라는 가정이다.
→ 그래서 **1단계(사업의 질)에서 ❌면 그 시점에서 분석을 중단**한다. 그 질문에 답할 수 없으면
내재가치의 58%가 근거를 잃기 때문이다. **4단계는 1단계 위에 서 있다.**

**용어** — **EPS**: 주당순이익, 1주가 1년에 벌어다 주는 돈 · **PER**: 주가÷EPS, 1년 이익의 몇 배 가격인가 ·
**할인율**: 미래 이익을 깎는 비율(높을수록 보수적) · **종료 PER**: 10년 뒤 이 주식이 받을 것으로 보는 PER

  참고로 **회사의 2030 목표는 매출 CAGR 6~10%**이므로, 요구치 6%는 **회사가 자기 목표의 최하단만 달성해도 충족**되는 수준이다.

  > ⚠️ **그래도 이것을 매수 근거로 쓰지 않는다 — 두 가지 이유:**
  > 1. **역DCF는 독립적인 증거가 아니다.** 주가가 내재가치보다 낮으면 요구 성장률은 **반드시** 가정보다 낮게 나온다.
  >    안전마진 19.8%와 **같은 사실을 다르게 표현한 것**일 뿐이다. 역DCF의 값어치는 새 정보가 아니라
  >    **"그 요구 성장률이 상식적으로 달성 가능한 숫자인가"를 눈으로 보게 해주는 것**에 있다.
  > 2. **관문은 그대로다.** 4단계 계산이 좋아져도 **안전마진 19.8% < 기준 20%**이고 **R2가 미해결**이다.
  >    계산 정정으로 매수 판정이 바뀌지 않는다 — 이 정정은 **틀린 문장을 고친 것이지 새로 좋아진 것이 아니다.**
