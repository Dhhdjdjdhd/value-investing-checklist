# 종목 분석 체크리스트 — NXP 세미컨덕터 (NXPI)

- 분석일: 2026-08-17 / 현재 주가: **$234.71** (8/14 종가) / 시가총액: 약 **$59.2B** (약 2.52억 주)
- 업종: 차량용·산업용 반도체 (마이크로컨트롤러, 레이더, 보안칩, 커넥티비티)
- 배경: 52주 고점 $339.95 대비 **−31%**. 2025년이 자동차 재고조정의 바닥이었고 2026년 회복 전환
- 데이터 기준: 2026 2분기 실적(매출 $3.5B) 반영, TTM은 2026년 6월 기준

## 1단계. 사업의 질 — **통과** (⚠️ 1개)

- [x] 무엇으로 버는지 한 문단: 자동차에 들어가는 반도체를 만든다. 차량용 마이크로컨트롤러, 레이더 칩, 차량 네트워크(이더넷 스위치), 전기차 배터리 관리, 디지털 키 같은 것들이다. 자동차 회사·부품사(티어1)에 팔고, 산업 장비·모바일에도 공급한다.
- [x] 10년 뒤에도 필요한가 ✅ — 차량이 소프트웨어 정의 차량(SDV)·전동화로 갈수록 **차량당 반도체 탑재량은 증가**
- [x] 경제적 해자 (2개 해당)
  - [x] **전환비용 — 설계 인(design-in) 락인**: 차량용 반도체는 **AEC-Q100 인증**을 통과하고 특정 차종에 설계 채택되면,
    그 차량 모델의 생애주기(**7~10년**) 동안 교체되지 않는다. 바꾸려면 재인증·재검증·리콜 리스크를 감수해야 한다.
    → **한 번 이기면 10년 매출이 확정**되는 구조. 코파트의 야드와 유사한 "시간이 지켜주는 해자"
  - [x] **규모의 경제 + 과점**: 차량용 MCU는 NXP·인피니언·르네사스·TI·ST의 **5사 과점**. 신규 진입은 인증 이력이 없어 사실상 불가
  - [ ] 브랜드 / 네트워크 효과 — ❌
- [x] 가격 결정력 ✅ — 설계 인 이후 재협상력이 공급자 쪽에 있음. 2분기 비GAAP 영업이익률 **35%**가 증거
- [ ] ⚠️ **예측 가능성 — 사이클성**: 자동차 생산과 재고에 매출이 좌우된다.
  FY2023 $13,276M → FY2025 $12,269M로 **2년 감소** 후 회복 중. 코파트와 달리 **명확한 순환 사업**

## 2단계. 경영진 — **조건부 통과** (⚠️ 2개)

- [ ] ⚠️ **CEO 교체 직후 — 검증 이력 부족**: 현 CEO **Rafael Sotomayor**(2분기 실적 코멘트 주체).
  장기간 조직을 이끈 Kurt Sievers의 후임으로, **자본배분 실적(track record)이 아직 없다.**
  ※ 취임 시점·경위는 본 분석에서 원문 확인 미완료 — **완주 전 위임장(DEF 14A)·8-K로 확인 필요**
- [ ] ⚠️ **$3.3B 규모 앰바렐라(Ambarella) 인수 추진 — 전략 전환 신호**
  - 명분: 엣지 AI·카메라·차량 내 AI 프로세싱을 더해 SDV 포트폴리오 완성 (전략적 정합성은 있음)
  - 우려: 전임 CEO가 **유기적 성장과 표적 제휴**를 고수해온 회사가 **시총의 5.6%를 한 번에 쓰는 인수**로 선회.
    보도 직후 **NXP 주가 −3%, 앰바렐라 +17%** — 시장은 "비싸게 산다"에 표를 던졌다
  - **인수가가 앰바렐라 시총($3.1~3.9B)과 거의 같다 = 프리미엄 거의 없음**은 그나마 완화 요인
- [x] 부채 관리 ✅ — D/E **1.48**(2022) → **1.20**(2025) → **0.93**(현재)로 꾸준히 개선
- [x] 주주환원 ✅ — 배당 연 **$4.06**(분기 $1.014), 배당성향 **34.6%**. 2021년 $0.5625 → 2023년 $1.014로 인상 후 유지

> 판정: ⚠️ 2개이므로 **조건부 통과**. 02 §2에 따라 **확신도는 "보통"까지만** 가능하다.
