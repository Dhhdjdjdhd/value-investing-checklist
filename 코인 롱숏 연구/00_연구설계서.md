# 코인 롱/숏 판단 연구 — 연구설계서 (사전 등록)

- 작성: 2026-11-21 / 상태: 설계 고정 → 백테스트 실행
- 요청: "지수 말고 코인으로, 롱/숏 적중률 53~55% 나오는 프로그램 설계 + 백테스트. 실제 돈은 넣지 않고 시뮬레이터로만 쓴다"
- 원칙: 아래 규칙·판정 기준은 **결과를 보기 전에 고정**한다. 결과를 본 뒤 추가하는 실험은 끝에 "사후 등록"으로 표시하고, 원래 판정은 지우지 않는다.
- 출발점: 차트분석 1~3차(지수·개별주에서 차트 규칙 대부분 실패, 200일선 방어 규칙만 쓸 만함)와 4차 P5(공포 신호 약한 경향만 있음).

---

## 1. 질문

"BTC·ETH에서 매일 롱 또는 숏을 정하는 규칙이, 비용을 뺀 뒤에도 **균형 적중률 53% 이상**이면서 단순 보유와 단순 추세규칙보다 나은가?"

## 2. 데이터

| 자료 | 출처 | 기간 |
|---|---|---|
| BTCUSDT·ETHUSDT 일봉 (현물) | 바이낸스 공개 API `/api/v3/klines` | 2017-08-17 ~ 2026-11-20 |
| BTCUSDT·ETHUSDT 무기한 선물 펀딩비 (8시간) | 바이낸스 `/fapi/v1/fundingRate` | 2019-09 ~ |
| 참고용 알트 5개: BNB·XRP·ADA·SOL·DOGE 일봉 | 바이낸스 | 상장 이후 |

- 일봉은 UTC 00:00 기준이다. 신호는 그날 종가로 정하고, **다음 날 시가(= 그날 종가와 사실상 같음)에 체결**한다.
- 펀딩비가 없는 2019-09 이전에는 표준값(8시간 0.01%, 하루 0.03%)을 쓴다.

## 3. 구간

| 구간 | 기간 | 포함된 국면 |
|---|---|---|
| 학습 | 2017-09-01 ~ 2022-12-31 | 2017 버블, 2018 −80%, 2020~21 강세, 2022 −75% |
| 검증 | 2023-01-01 ~ 2026-11-20 | 현물 ETF 이후 기관화 구간 |

- ETH는 **독립 확인 시장**이다. BTC에서 고른 규칙을 그대로 적용한다.
- 알트 5개는 생존편향이 커서(지금 살아남은 코인만) 판정에 쓰지 않고 참고로만 본다.

## 4. 예측 단위

h = 1일, 3일, 7일. h일 보유 규칙은 매일 1/h씩 새로 들어가고 h일 뒤에 나오는 **겹치는 분할 포지션**으로 계산한다. 그래서 포지션은 −1 ~ +1 사이 값이다.

## 5. 규칙 (모두 롱 +1 / 숏 −1, 시험 규칙 수 기록)

| 번호 | 이름 | 정의 |
|---|---|---|
| T1-L | 시계열 모멘텀 | 지난 L일 수익률 부호. L = 7, 14, 28, 56 |
| T2-N | 이동평균 위치 | 종가 > N일 평균이면 롱, 아니면 숏. N = 20, 50, 100, 200 |
| T3 | 이동평균 교차 | 20일 평균 > 100일 평균이면 롱 |
| R1 | 단기 반전 1일 | 어제 수익률의 반대 부호 |
| R3 | 단기 반전 3일 | 지난 3일 수익률의 반대 부호 |
| F1 | 펀딩비 역발상 | 7일 평균 펀딩비가 지난 180일 중앙값보다 높으면 숏, 낮으면 롱 (펀딩비 있는 2019-09 이후만) |
| F2 | 추세 + 과열 필터 | T2-50을 따르되, 7일 평균 펀딩비가 지난 365일의 상위 10%이면 숏 |
| D1 | 요일 | 학습 구간에서 그 요일의 평균 수익이 플러스면 롱, 아니면 숏 (h=1만) |
| M1 | 로지스틱 회귀 (고정) | 특징: 7·14·28·56일 수익률, 20·50·200일 평균과의 거리, 20일 변동성, 7일 평균 펀딩비, 요일. 학습 구간으로 한 번 학습 후 고정 |
| M2 | 로지스틱 회귀 (확장 재학습) | M1과 같은 특징, 매년 1월 1일에 그 전까지 데이터 전부로 다시 학습 (검증 구간에서만 평가) |

- 규칙 수: T1 4 + T2 4 + T3 1 + R 2 + F 2 + M 2 = 15개 × h 3개 + D1 1개 = **46개**.
- 모델 파라미터: 로지스틱 회귀 L2 규제 C = 1.0, 특징 표준화(학습 구간 평균·표준편차). 바꾸지 않는다.

## 6. 기준선

| 기준선 | 정의 |
|---|---|
| B&H | 계속 롱 (현물 보유와 같고, 펀딩비는 내지 않음) |
| TF200 | 200일 평균 위면 롱, 아래면 현금 (차트분석 1~3차에서 유일하게 쓸 만했던 규칙) |
| 적중률 기준 | 균형 적중률 50% (무작위) |

## 7. 비용

- 무기한 선물 기준: 편도 **0.07%** (수수료 0.05% + 슬리피지 0.02%) × 포지션 변화량.
- 펀딩비: 롱은 내고 숏은 받는다(실제 기록). 민감도: 비용 2배.

## 8. 측정

| 지표 | 정의 |
|---|---|
| 균형 적중률 (BA) | ½ × [상승일 중 롱 예측 비율 + 하락일 중 숏 예측 비율]. "상승"은 h일 뒤 수익 > 0 |
| 단순 적중률 | 신호 부호 = h일 뒤 수익 부호인 비율 (참고. 상승 비율이 높으면 부풀려짐) |
| 롱·숏 각각의 적중률 | 숏 신호가 실제로 맞았는지 따로 봄 |
| 비용 뺀 연수익·Sharpe·MDD | 일간 수익 기준, 365일 연율화 |
| 부트스트랩 | 30일 블록, 1,000회. (규칙 Sharpe − B&H Sharpe) > 0 인 비율 |

## 9. 판정 (미리 고정)

어떤 (자산, 구간)에서 "통과"하려면 아래 세 가지를 **모두** 만족해야 한다.
1. 균형 적중률 ≥ 53%
2. 비용 뺀 Sharpe > B&H Sharpe **그리고** > TF200 Sharpe
3. 부트스트랩 우위 확률 ≥ 90% (B&H 대비)

| 판정 | 조건 |
|---|---|
| **추천** (시뮬레이터 탑재) | BTC 학습 + BTC 검증 + ETH 검증 모두 통과 |
| **보류** | BTC 학습 + BTC 검증만 통과 |
| **탈락** | BTC 검증 실패 |

M2는 학습 구간 성적이 없으므로 BTC 검증 + ETH 검증 통과면 "보류", 아니면 "탈락"이다.

## 10. 엔진 검증

- 룩어헤드 점검: 데이터를 2021-12-31에서 자른 뒤 계산한 신호가 전체 데이터로 계산한 그 날짜까지의 신호와 같아야 한다.
- 무조건 롱 규칙의 비용 0 수익이 현물 보유 수익과 같아야 한다.

## 11. 한계 (미리 적어 둠)

- 코인 역사가 짧다. BTC 학습 구간은 약 5년, 독립 국면은 강세 2번·약세 2번뿐이다.
- 바이낸스 한 거래소의 가격이다. 2017~2018년에는 거래소별 가격 차이가 컸다.
- 겹치는 표본 때문에 적중률의 표준오차는 단순 계산보다 크다. 그래서 판정은 블록 부트스트랩을 쓴다.
- 46개 규칙을 시험했으므로 하나쯤은 운으로 통과할 수 있다. BTC 학습·검증 모두 통과에 ETH까지 요구하는 이유다.
- 실제 시뮬레이터에서는 체결 지연, 레버리지 청산, 거래소 위험이 추가된다. 이 연구는 레버리지 1배 기준이다.
