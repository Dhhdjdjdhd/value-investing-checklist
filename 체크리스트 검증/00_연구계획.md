## 2. 원칙

1. **시점 정보만 사용**: 회계연도 재무는 기말 + 95일 후부터 사용 (10-K 공시 지연 반영).
2. **생존편향 관리**: 재무는 SEC frames(상장폐지 기업 포함)에서 받는다. 주가가 없는 상장폐지 기업은 따로 세어서 영향을 추정한다. 1차 비교 기준은 **같은 유니버스의 동일비중**(같은 편향을 공유)으로 한다.
3. **기간 분할**: 학습 2011~2018 / 검증 2019~2026-10. 최적화는 학습 구간에서만, 검증은 마지막에 한 번만.
4. **최적화 = 문서 규칙의 숫자 조정**: 새 규칙을 발명하지 않고, 문서에 있는 문턱(ROIC, 안전마진, 종료 PER 배수·상한, 할인율, 종목 수, 갈아타기 격차, 경기순환 제외 등)을 흔들어 본다. 학습·검증 모두에서 개선되고 이웃 파라미터에서도 유지될 때만 "수정안"으로 채택한다.
5. 비용: 편도 0.1%, 리밸런스는 월 1회.

## 4. 한국(코스피) — ROIC 관문 선택지 A·B·C (2026-11-23 사전 등록)

- 배경: 선택지 A(ROIC 5년 중앙값 15% 그대로, `src/kr_backtest.py`, 11-19 실행)는 관문 통과가 학습 구간 중앙 13개뿐이라 20종목을 못 채웠다(평균 13종목).
- 공통 조건은 A와 같다: 2018-04 시작, 학습 2018-04~2022-12 / 검증 2023-01~, 시총 하한 규칙(1조·5천억·3천억 중 통과 중앙 ≥30인 가장 높은 값, 없으면 3천억), v2(20종목·분기 점검·30위 완충), 편도 0.2%. 데이터도 같다(가격 2026-11-09까지, 갱신하지 않음).
- 바꾸는 것은 **ROIC 관문 문턱(`roic_min`)뿐**이다. S등급 기준(`roic_s` 20%)과 나머지 관문은 그대로 둔다.

| 선택지 | ROIC 관문 |
|---|---|
| A | 5년 중앙값 ≥ 15% (기존) |
| B | 10%·12%·15% 중 **학습 구간 통과 종목 수 중앙 ≥ 20**인 가장 높은 문턱. 수익률은 보지 않고 종목 수만으로 고른다. 없으면 10% |
| C | 상대 순위: 같은 결산연도(cy) 후보 중 ROIC 5년 중앙값 **상위 30%**(70번째 백분위 이상). 후보 = 제외 업종 아님 + 결산일 시총 ≥ 채택 하한 + 5년 이력. 월별 대신 결산연도 단위로 정한다(관문 판정이 연도행 단위라서) |

- **선택(미리 고정)**: A·B·C 중 **학습 구간 v2 Sharpe가 가장 높은 것**. 검증 구간은 고른 뒤 한 번만 보고, 결과가 나빠도 바꾸지 않는다.
- **함께 보고**: KODEX 200·같은 우주 동일비중 대비 부트스트랩, 이상치 133개사 제외 실험(`panel/flags.csv`), 평균 보유 종목 수, 삼성전자·SK하이닉스 편입 여부.
- 실행: `py src/kr_roic.py` → `results/kr_roic_*.csv`
