# 차트 패턴 매매 알고리즘 연구 — 연구계획

- 시작일: 2026-10-23
- 책임자(매니저): 메인 세션 / 작업자: value-investing-checklist-f9 세션
- 목표: 과거 일봉 데이터에서 "어떤 패턴이 나왔을 때 매수/매도하면 승률·기대수익이 좋았는가"를 **백테스트로 검증**

## 1. 핵심 원칙 (과최적화 방지)

1. **기간 분할**: 학습(In-Sample) ~2014-12-31 / 검증(Out-of-Sample) 2015-01-01~현재. 파라미터는 학습 구간에서만 고르고, 검증 구간은 마지막에 한 번만 본다.
2. **기준선 비교**: 모든 신호는 (a) 같은 종목·같은 보유기간의 무작위 진입, (b) 단순 보유(Buy&Hold)와 비교. "승률 60%"라도 기준선이 58%면 의미 없음.
3. **비용 반영**: 편도 0.05% 수수료+슬리피지 기본, 민감도는 0.1%/0.2%까지.
4. **체결 현실성**: 신호는 당일 종가로 판정 → **다음날 시가** 진입(룩어헤드 방지).
5. **다중검정 보정**: 수십 개 패턴을 시험하므로 t-통계량 기준을 높게(|t|>3) 잡고, 부트스트랩으로 재확인.
6. **견고성**: 미국 종목에서 찾은 규칙이 한국 종목·ETF·다른 시기에서도 통하는지 교차 확인.
7. **생존편향 고지**: 현재 상장 종목 위주라 결과가 낙관적일 수 있음. 몰락한 종목(GE, C, AIG, INTC 등)을 의도적으로 포함.

## 2. 데이터

- 출처: Yahoo Finance chart API (일봉, 상장 이후 전체, 수정주가)
- 유니버스: 미국 지수 ETF, 섹터 ETF, 대형주 약 80개, 한국 대표주 약 15개
- 저장: `data/raw/<티커>.csv` (date, open, high, low, close, adj_close, volume), 수정 OHLC는 adj_close/close 비율로 계산

## 3. 시험할 패턴 (1차 후보)

| 계열 | 패턴 |
|---|---|
| 평균회귀 | RSI(2)<10, N일 연속 하락, 볼린저 하단 이탈, 종가가 N일 최저, 큰 갭하락 |
| 추세추종 | 골든크로스(50/200), 52주 신고가 돌파, 돈치안 20/55 돌파, MACD 신호선 교차 |
| 변동성 | NR7(7일 중 최소 변동폭), 인사이드데이, 거래량 급증 |
| 캔들 | 장악형(Engulfing), 망치형, 3일 연속 양봉/음봉 |
| 필터 | 200일선 위/아래(추세 필터) 조합 |

## 4. 평가 지표

- 고정 보유기간(1·5·10·20일) 사건연구: 평균수익, 승률, t-통계, 기준선 대비 초과
- 규칙 기반 매매(진입+청산 규칙): CAGR, MDD, 샤프, 승률, 손익비, 거래수, 노출도
- 연도별 안정성, 종목별 일관성(몇 %의 종목에서 양(+)인가)
