# 대안전략 연구 — 연구계획 (사전 등록)

- 시작: 2026-11-16 / 요청: "가치투자 체크리스트가 S&P500보다 확실히 낫지 않으니 다른 방법을 찾아보자"
- 원칙: **규칙과 판정 기준을 실험 전에 이 문서에 고정**한다. 선택은 학습 구간 성적으로만 하고, 검증 구간은 한 번만 본다. 결과가 나쁘게 나와도 규칙을 사후에 바꾸지 않는다(바꾸면 "사후 변경"으로 표시).

## 이미 확인된 것 (출발점)

| 연구 | 결론 |
|---|---|
| 체크리스트 검증 (10/23) | 품질 관문은 유효, 목표가 대기·집중은 해로움. v2(품질·가치 순위 20)는 Sharpe 1.07 vs SPY 0.99, 우위 확률 70% — 확실하지 않음 |
| 차트 패턴 (10/23) | 학습 구간 상위 규칙 전부 검증 구간에서 단순 보유보다 못함 |
| ML (10/23) | 대형주에선 통과, 생존편향 없는 ETF·2016년 이후에서 짐 |
| 국채 혼합 (11/15) | 80/20(30년 국채 환헤지)으로 원화 MDD −41% → −28% |

## A. 종목 선택 — 품질 관문 + 다른 신호

- 데이터·엔진: `체크리스트 검증`의 SEC 최초 공시값 패널, 월간 시뮬레이터 그대로(시총 ≥ $10B, 경기순환 섹터 제외, 편도 0.1%)
- 구간: 학습 2011.04~2018.12 / 검증 2019.01~2026.10
- 보유 방식은 v2와 같게 고정: **20종목 동일비중, 3개월마다 점검, 보유 종목은 30위 안이면 유지**. 바뀌는 것은 순위 매기는 방법뿐이다.
- 신호 (같은 달 후보 안의 백분위로 더한다)
  - Q: ROIC 5년 중앙값 / V: (FCF−SBC)÷시총  (= v2의 qv)
  - M: **12-1 모멘텀** — 직전 달 말 ÷ 12개월 전 달 말 총수익지수 − 1 (최근 1개월 제외)
  - B: **주식 수 감소** — 최신 연간 희석주식수의 전년 대비 감소율(분할 보정)
  - Y: 주주환원 수익률 — (배당 + 자사주 매입) ÷ 시총 (배당 태그 누락이 많아 누락은 0으로 둔다 — 근사)

| 규칙 | 관문 | 순위 |
|---|---|---|
| A0 (기준 = v2) | 통과 | Q+V |
| A1 | 통과 | Q+V+M |
| A2 | 통과 | Q+V+0.5M |
| A3 | 통과 | Q+V+2M |
| A4 | 통과 | Q+V, 단 M 하위 1/3 제외 |
| A5 | 통과 | M만 |
| A6 (참고: 순수 모멘텀) | 없음(대형주 전체) | M만 |
| A7 | 통과 | Q+V+B |
| A8 | 통과 | Q+V+Y |
| A9 | 통과 | Q+V+M+B |

- **채택 기준**(미리 고정): A1~A9 중 학습 Sharpe 1위를 후보로 한다. 후보가 ① 학습 Sharpe가 A0보다 0.05 이상 높고 ② 검증 Sharpe가 A0 이상이면 채택한다. 아니면 "v2 유지".
- **"S&P500보다 확실히 낫다"의 기준**: 전체 구간 블록 부트스트랩에서 Sharpe 차이 > 0일 확률 ≥ 90%.
- 견고성(채택 후보만): 종목 수 15/20/30 × 점검 1/3/6개월, 비용 0.3%, 재작성 공시값(last) 데이터.
- **현실 점검**(생존편향 없음): 실제로 운용된 미국 팩터 ETF(MTUM 모멘텀, QUAL 품질, SPHQ 품질, SPMO 모멘텀)의 상장 이후 성과를 SPY와 비교한다. 백테스트에서 좋았던 신호가 실제 상품에서도 나타났는지 본다.

## B. 자산배분 — 원화 기준, 연금계좌에서 실행 가능한 규칙

- 사용자 실제 구성 기준: 주식 = S&P500 원화 환노출(360750과 같은 성격), 채권 = 미국 30년 국채 **환헤지**(453850 성격, ^TYX로 합성 — 11/15 검증: TLT와 상관 높음), 현금 = 원화 CD91
- 구간: 학습 1991.01~2008.12 / 검증 2009.01~2026.10, 월간, 신호는 월말 → 다음 달 적용, 전환 비용 편도 0.1%
- 연금계좌 안의 ETF 교체는 매매차익 과세가 없으므로 세금은 반영하지 않는다(인출 시 연금소득세는 모든 규칙에 같음).

| 규칙 | 내용 |
|---|---|
| B0 | 주식 100% |
| B1 | 주식 80 / 30년 국채 20, 연 1회 리밸런싱 (현재 계획) |
| B2 | 추세: S&P500(달러)이 10개월 이동평균 위면 주식 100%, 아래면 30년 국채 100% |
| B3 | 추세: B2와 같되 아래면 원화 현금 |
| B4 | 80/20 + 추세: 주식 몫(80%)만 B2 규칙 적용 |
| B5 | 절대 모멘텀: S&P500 12개월 수익률 > 미국 3개월 금리면 주식, 아니면 30년 국채 |
| B6 | 변동성 맞추기: 주식 비중 = min(1, 15% ÷ 최근 6개월 원화 변동성), 나머지 30년 국채 |

- 판정(미리 고정): 노후자금이므로 **수익보다 큰 손실 회피가 우선**. 학습 구간에서 B1 대비 ① MDD가 5%p 이상 개선되고 ② 연수익이 1%p 넘게 줄지 않는 규칙을 후보로, 검증 구간에서도 같은 조건을 만족하면 "추천", 학습에서만 만족하면 "보류".
- 추가 보고: 최악 연도, 위기 구간(닷컴·금융위기·코로나·2022 금리급등) 낙폭, 연간 교체 횟수(실행 부담).

## 한계 (미리 적어 둠)

- A는 상장폐지 기업 186개가 빠진 생존편향이 그대로다. 모멘텀은 생존편향에 특히 민감할 수 있어 현실 점검(팩터 ETF)을 함께 본다.
- A의 결과는 미국 개별주라 연금계좌에서 직접 실행할 수 없다(법인·일반 계좌 + 양도세 22%).
- B의 2009년 이전 30년 국채 수익은 금리로 만든 합성값이다.
