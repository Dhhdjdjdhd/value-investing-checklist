# Finviz 스크리너 실행 방법 — 재현 가능한 절차서

> **2026-10-21 전면 개편: "싼 것부터 찾기" → "좋은 기업부터 찾고, 가격은 기다리기".**
> 종전 파이프라인(스크린 A 저PER ∩ 스크린 B 낙폭)은 00의 점검 순서(① 사업 → ④ 가격)를 거꾸로 돌렸다.
> 첫 관문에서 가격으로 걸렀기 때문에 걸리는 것은 대부분 **싼 이유가 있는 기업**이었고
> (3회차 누적: INTU 판단 오류, NVO·LULU·MKC·INFY·WIT·QCOM 탈락, 금광·태양광 다수),
> V·MA·COST·ISRG·ASML 같은 기업은 **한 번도 걸리지 않았다.**
>
> API 키 없이 Finviz 스크리너에 **URL로 조건을 넣어 직접 조회**한다.
> 우주(universe): Finviz 커버리지 = 미국 상장 전체 (ADR 포함, 약 1만 종목).
> **한국 종목은 우주에 넣지 않는다** (2026-10-21 결정 — 04 "우주 범위" 참조).
> AI 어시스턴트에게 시킬 때: **"품질 우주 갱신해줘"**(§3 [1]~[3]) 또는 **"낙폭 스크린 돌려줘"**(§3 보조) — 이 문서가 재현 절차의 원본.

## 1. 실행 URL

### 스크린 D — 품질 우주 (주력, PER·낙폭 조건 없음)
```
https://finviz.com/screener.ashx?v=111&f=cap_largeover,fa_roi_o15,fa_eps5years_pos,fa_sales5years_pos&ft=4
```
- 2026-10-21 첫 실행: **184개**
- 같은 조건으로 재무 컬럼을 보려면 `v=161`(ROIC·마진·D/E), 52주 고점 대비는 `v=171`

### 스크린 B — 낙폭 (보조: 품질 우주에 새 기업을 들이는 발견 통로)
```
https://finviz.com/screener.ashx?v=111&f=cap_largeover,fa_roe_o15,fa_opermargin_pos,ta_highlow52w_b30h&ft=4
```
- 2026-10-22: `fa_debteq_u1`(D/E < 1) 삭제 — 스크린 D에서 뺀 이유(§2, 자사주로 D/E 왜곡 → MA·KO 탈락)와 같다

### ~~스크린 A — 우량 + 합리적 가격~~ (2026-10-21 폐기, 기록용)
```
https://finviz.com/screener.ashx?v=111&f=cap_largeover,fa_roe_o15,fa_debteq_u1,fa_fpe_u20,fa_eps5years_pos,fa_sales5years_pos&ft=4
```
- 폐기 사유: Forward PER < 20이 S·A등급 후보를 가격만으로 걸러냈다. 가격 판정은 이제 완주 분석의 등급별 문턱(02 §1)이 한다.

### 페이지 넘기기
- 한 페이지 20종목. URL 끝에 `&r=21`(2페이지), `&r=41`(3페이지)… 추가
- 첫 페이지의 `#1 / N Total`에서 N을 읽는다 → N÷20 올림 = 필요한 페이지 수
- 행 데이터는 HTML의 `data-row-key="티커"`와 `data-column-id="sector|industry|roi|…"` 속성에서 뽑는다 (2026-10 기준 마크업)

## 2. 필터 코드 해설

| 코드 | 뜻 | 쓰는 곳 | 우리 체크리스트 대응 |
|---|---|---|---|
| `cap_largeover` | 시가총액 $10B 이상 | D·B | 대형 우량주 한정 |
| `fa_roi_o15` | **ROIC 15% 초과** (Finviz 표기는 ROI지만 종목 페이지에는 ROIC로 나온다) | D | 3단계 ROIC 기준과 동일 |
| `fa_eps5years_pos` | EPS 5년 성장 플러스 | D | 3단계 이익 일관성 (근사) |
| `fa_sales5years_pos` | 매출 5년 성장 플러스 | D | 성장의 진위 |
| `fa_roe_o15` | ROE 15% 초과 (최근치) | B | 3단계 ROE |
| `fa_debteq_u1` | 부채/자본 1 미만 | ~~B~~ (2026-10-22 삭제) · A(폐기) | 3단계 부채 (근사) |
| `fa_opermargin_pos` | 영업이익 흑자 | B | 적자 기업 제외 |
| `ta_highlow52w_b30h` | 52주 고점 대비 −30% 이상 | B | `b20h`, `b40h`, `b50h`로 조절 가능 |

**스크린 D에 넣지 않은 조건과 이유** (첫 실행에서 관심 종목 17개로 대조해 정했다)
- **D/E < 1**: 자사주를 많이 사는 기업은 자기자본이 줄어 D/E가 부풀려진다. ROE가 왜곡되는 것과 같은 원리다(00 §3).
  이 조건이 있으면 **MA(4.39)·KO(1.20)가 빠진다.** 부채는 3단계 "장기부채 ÷ 순이익 ≤ 3~4배"로 본다
- **영업이익률 ≥ 20%**: **COST(3.85%)가 빠진다.** 박리다매형 해자는 마진이 아니라 회전율로 돈을 번다
- **ROIC ≥ 20%**: META(18.4%)·KO(19.6%)·ISRG(16.3%, 현금 과다)가 빠진다. 20%는 S등급 조건이지 우주 진입 조건이 아니다 — A등급 후보까지 담으려면 15%가 맞다
- 이렇게 해도 **CDNS(ROIC 14.75%, 인수 직후)는 빠진다.** 이런 거짓 탈락은 §3 [1]의 "관심 종목 수동 편입"으로 보완한다

## 3. 실행 절차 (파이프라인)

```
[1] 품질 우주 갱신 (반기 1회)  →  [2] 등급 판정  →  [3] 간이 밸류·목표가  →  [4] 가격 알림 → 완주 → 매수
```

**[1] 품질 우주 갱신 — 반기 1회 (2월 말·8월 말, 연간 실적이 대부분 나온 뒤)**
1. 스크린 D 실행 → 전 페이지 수집 (티커·회사·섹터·업종·시총·ROIC·영업이익률·D/E·PER·52주 고점 대비)
2. **섹터 제외** ([[04.스크리너_조건]]): 소재·원자재·에너지·메모리/저장장치·태양광·주택건설·해운·항공(경기순환),
   보험·증권·자산운용·은행·리츠(지표 왜곡), 중복 상장. 카드 네트워크(V·MA)·금융 데이터/거래소(MCO·MSCI)·보험 중개(AON)는 **남긴다** — 대차대조표가 아니라 수수료로 버는 사업이다
3. **수동 편입**: 버크셔 13F 상위 보유, 스크린 B에서 발견한 기업, 거짓 탈락으로 확인된 기업(CDNS 등)
4. **기존 판정 표시**: 탈락·패스·청산·영역 제외(00 §6) 종목은 재검토 예정일 전까지 그대로 둔다
5. 결과 저장: `02.종목분석\품질우주_YYYYMMDD.md` — 직전 회차와 diff(새로 들어온 / 빠진 종목과 이유)

**[2] 등급 판정 — 신규 편입 종목만, 기업당 연 1회**
- 1~3단계 **간이** 판정으로 S / A / 일반 **잠정** 등급을 매긴다 (02 §1 등급표)
- 간이 판정에서 볼 것: 10년 ROIC 추이, 10년 EPS 일관성(진입대기 문서 §2-3의 두 기준), 해자 유형 수, FCF ÷ 순이익, 경영진 적신호
- 여기서 1단계 ❌(해자 없음·10년 지속성 불명)가 나오면 우주에서 뺀다
- **가격은 보지 않는다.** 등급이 가격에 오염되지 않게 [3]보다 먼저 끝낸다

**[3] 간이 밸류·목표가 — 등급 판정을 통과한 종목**
- 템플릿 01 4단계 ② 가정 규칙(원본)으로 기본 내재가치 산출
- 목표 매수가 = 기본 내재가치 × 등급 배수 (S 0.9 / A 0.85 / 일반 0.8)
- `종목 모니터링/drawdown-monitor/config.json`에 등록 (가격선: 기본 / 목표 / 보수 / 2회차 / 3회차)

**[4] 가격 알림 → 완주 분석 → 매수**
- 목표가 도달 알림 → 그 종목만 템플릿 01 전체로 완주 (02 §1 "목표가 도달 ≠ 자동 매수")
- 완주 결과 등급이 잠정 등급과 다르면 **완주 쪽이 원본**이다

**보조 — 스크린 B (낙폭)**
- 분기 1회(실적 시즌 뒤) + 시장 급락 시(지수 −10% 이상)
- 용도는 두 가지뿐이다: ① **품질 우주에 이미 있는 종목**이 걸리면 → [3]의 목표가와 대조 ② **우주에 없는 종목**이 걸리면 → [2]로 보내 편입 여부 판정
- 스크린 B 단독으로는 완주 분석에 보내지 않는다 (싼 이유가 있는 기업을 먼저 찾게 된다)

## 5. 한계 (매번 상기할 것)

- **스크린 D는 "좋은 기업"이 아니라 "좋은 숫자"를 거른다**: 해자·경영진은 [2]에서만 판정된다. 우주 편입 ≠ 매수 후보
- **거짓 탈락**: 인수 직후 ROIC가 일시 하락한 기업(CDNS), 영업권이 큰 기업(세일즈포스) → 수동 편입으로 보완
- **거짓 통과**: 사이클 정점 기업은 ROIC·EPS 성장이 모두 좋아 보인다 → 섹터 제외가 1차 방어선, [2]의 10년 일관성이 2차 방어선
  (반도체 장비 AMAT·LRCX·KLAC·ASML은 메모리가 아니라 남겨두지만, 업종 자체가 사이클이므로 [2]에서 이익의 정점 여부를 확인할 것)
- Finviz `EPS past 5Y`는 5년 한 구간의 성장률이다. 중간에 꺾였다 회복한 기업도 통과한다 → 10년 일관성은 [2]에서 SEC 원문으로
- 수치는 조회 시점 스냅샷 — 판단은 완주 분석에서 확정치로
