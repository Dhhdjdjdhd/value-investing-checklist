> 우주(universe): Finviz 커버리지 = 미국 상장 전체 (약 1만 종목). 한국·유럽 종목은 이 방법으로 불가.

### 페이지 넘기기
- 한 페이지 20종목. URL 끝에 `&r=21`(2페이지), `&r=41`(3페이지), `&r=61`, `&r=81`, `&r=101`… 추가
- 첫 페이지에 "Total: N개" 표시 → N÷20 올림 = 필요한 페이지 수

## 2. 필터 코드 해설 (조건 수정 시 참고)

| 코드 | 뜻 | 우리 체크리스트 대응 |
|---|---|---|
| `cap_largeover` | 시가총액 $10B 이상 | 대형 우량주 대상 한정 |
| `fa_roe_o15` | ROE 15% 초과 (최근 기준 — 5년 평균 아님 주의) | 3단계 ROE |
| `fa_debteq_u1` | 부채/자본(D/E) 1 미만 | 3단계 부채 (근사) |
| `fa_fpe_u20` | Forward PER 20 미만 | 4단계 1차 필터 (A 전용) |
| `fa_eps5years_pos` | EPS 5년 성장 플러스 | 3단계 이익 일관성 (근사) |
| `fa_sales5years_pos` | 매출 5년 성장 플러스 | 성장의 진위 |
| `fa_opermargin_pos` | 영업이익 흑자 | 적자 기업 제외 (B 전용) |
| `ta_highlow52w_b30h` | 52주 고점 대비 −30% 이상 | 공포 = 기회 후보 (B 전용). `b20h`, `b40h`, `b50h`로 조절 가능 |

- 다른 필터가 필요하면: Finviz 화면에서 조건을 클릭해 만들면 URL에 코드가 나타남 — 그걸 복사

## 3. 실행 절차 (파이프라인)

1. **스크린 A 실행** → 전 페이지 수집 (티커·회사명·섹터·PER·시총)
2. **스크린 B 실행** → 전 페이지 수집
3. **A ∩ B 교집합** 추출 — 우량 + 안 비쌈 + 많이 빠짐 = 최우선
4. **섹터 제외 적용**: 금광·원자재·에너지·메모리반도체·해운·항공(경기순환 — 별도 플레이북), 은행·보험(지표 왜곡). 태양광 등 사이클성 개별 판단
5. **결과 저장**: `02.종목분석\스크리닝_Finviz_YYYYMMDD.md` (전체 목록 + 교집합 + 제외 근거)
6. **직전 회차와 비교(diff)**: 새로 걸린 종목 = 새 후보 / 빠진 종목 = 가격 회복 or 지표 악화 — 둘 다 기록
7. → 새 후보만 **간이 관문**(해자 / 싼 이유의 성격 / 판별 질문)으로: `후보목록_YYYYMMDD.md`
8. → 생존자만 **완주 분석** (템플릿 + 보고서 + 03 장부)

## 4. 재실행 주기

- **정기: 분기 1회** — 실적 시즌 끝난 뒤 (1월 말·4월 말·7월 말·10월 말경)
- **수시: 시장 급락 시** (지수 −10% 이상 조정) — 스크린 B에 새 종목이 쏟아지는 타이밍
- 스크린 C(버크셔 보유 × 낙폭 교차, [[04.스크리너_조건]] 참조)도 같은 주기로: 분기 13F 발표 후 버크셔 상위 보유 목록을 스크린 B 결과와 대조

## 5. 한계 (매번 상기할 것)

- **거짓 탈락 존재**: 세일즈포스는 ROE 11%(영업권 왜곡)로 이 필터에 안 걸렸지만 완주 분석에선 "매수 가능" — 스크리너는 보완재지 대체재가 아님
- **거짓 통과 존재**: 나이키는 B를 통과했지만 완주에서 안전마진 −35% 탈락 — 통과 = "검사할 가치", 합격 아님
- ROE는 최근치라 사이클 정점 기업(하이닉스류)이 통과해버림 — 섹터 제외 규칙이 방어선
- 수치는 조회 시점 스냅샷 — 목록의 PER·시총은 참고용, 판단은 완주 분석에서 확정치로
- trailing PER 열은 일회성 이익에 왜곡될 수 있음 (맥코믹 8.3배 착시 사례 — 너무 싸 보이면 의심부터)
