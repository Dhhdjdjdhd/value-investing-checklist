W3-A. 생존편향 추정 (작업자 W3, 2026-11-22)
============================================================
방법은 부록_W3.md A절에 결과를 보기 전에 적어 두었다. 코드: src/W3_survivorship.py, 원자료: results/W3_survivorship_sim.csv

■ 결론 (판정에 쓸 숫자)
  보정 Sharpe = 관측 Sharpe − 편향

  편향(Sharpe 단위, 저 / 중 / 고 시나리오)
                               학습 2003~2015          검증 2016~2026
  단기 반전형 (C3에 해당)      +0.04 / +0.10 / +0.20   +0.01 / +0.02 / +0.06
  S1 단독                      +0.03 / +0.06 / +0.13   +0.00 / +0.02 / +0.04
  반전+느린 신호 (C1·C2에 해당) −0.07 / −0.17 / −0.33   −0.02 / −0.05 / −0.12

  권고: §9의 "생존편향 보정 뒤 Sharpe@10bp > 0.5" 조건에는 검증 구간의 고 시나리오를 쓴다.
    - C3가 뽑히면: 보정 Sharpe = 관측 − 0.06
    - C1 또는 C2가 뽑히면: 보정 Sharpe = 관측 − 0.00
      (시뮬레이션은 음의 편향, 즉 생존 자료가 오히려 불리하다고 나오지만 유리한 쪽 보정은 주지 않는다)
  즉 상장폐지 누락만으로는 판정을 뒤집을 크기가 아니다. 다만 아래 "재지 못한 것" 2번은 따로 본다.

■ 1. 빠진 종목의 비율
  - 가격 자료 2,190종목은 전부 2026-10까지 살아 있는 종목이다(상장폐지 0개).
  - 유니버스 조건(252일 이력, 직전 종가 $5 이상)을 만족하는 생존 종목 수
      2003년 866 / 2006년 1,067 / 2010년 1,217 / 2016년 1,554 / 2020년 1,768 / 2026년 2,018
    2003년에는 자격 종목 866개 중 500개를 뽑는다. 즉 상위 58%까지 내려가서 채운다.
  - 상한: C_survivorship.txt의 "매출 10억 달러 이상인데 주가 없음" 비율은 학습 49%, 검증 34%, 최근 16%다.
    처음부터 상장 주식이 없던 공시사가 섞여 있어 실제보다 크다.
  - 추정: 당시의 진짜 거래대금 상위 500 가운데 지금 자료에 없는 종목은
      학습 구간 평균 약 35~50%, 검증 구간 평균 약 10~30%
    로 본다. 이 범위는 위 상한과 "2000년대 초 대형주의 40% 안팎이 지금은 티커가 없다"는 일반 지식에 기댄 추정이고,
    당시 구성 종목 명단으로 직접 센 값이 아니다.
  - 빠진 종목의 대부분(대략 80~90%)은 피인수·합병이고, 파산·부실로 사라진 종목은 일부다. 이 비율도 추정이다.

■ 2. 주입 시뮬레이션
  - 생존 종목으로 대리 전략 3개를 돌리고(종가 신호, 섹터 중립 없음, t+1 종가 체결, 비용 0),
    가상의 실패 종목을 유니버스에 넣어 Sharpe 변화를 쟀다. 시나리오마다 난수 20회 평균.
  - 실패 경로: 70%는 120~250일에 걸쳐 약 −85%, 30%는 60일간 −50% 뒤 하루 −60%와 다음 날 −100%.
  - 연간 주입 개수(저/중/고): 학습 1 / 2.5 / 5, 검증 0.3 / 1 / 2.5

  기준(생존 종목만)             Sharpe 학습   검증    연수익 학습  검증    변동성 학습  검증
    a. S1                       0.76       0.23    4.6%       1.9%    6.0%       8.3%
    b. S1+S2                    1.13       0.43    6.8%       3.5%    6.0%       8.3%
    c. S1+S2+S8+S10+S11         0.38       0.07    2.9%       0.6%    7.5%       9.4%
  (이 수치는 W1 엔진과 다른 대리 전략의 비용 전 값이다. 판정용이 아니다.)

  편향 = 기준 Sharpe − 주입 후 Sharpe (괄호는 난수 20회의 표준편차)
                      학습 저        중            고            검증 저        중            고
    a. S1             0.025(0.017)  0.062(0.036)  0.127(0.050)  0.005(0.007)  0.015(0.015)  0.038(0.023)
    b. S1+S2          0.042(0.018)  0.103(0.030)  0.203(0.041)  0.008(0.006)  0.022(0.015)  0.060(0.020)
    c. 반전+느린 신호  −0.068(0.017) −0.168(0.026) −0.327(0.042) −0.015(0.008) −0.047(0.017) −0.119(0.027)

  연수익으로는 반전형이 학습 0.2~1.1%p, 검증 0.1~0.5%p 부풀려진다.

  해석
  - 반전 신호는 무너지는 종목을 계속 사므로, 그 종목이 자료에 없으면 수익이 부풀려진다. 방향은 설계서 예상과 같다.
  - 크기가 작은 이유: 순위 비중이라 한 종목의 최대 비중이 약 0.4%이고, 종가가 $5 아래로 내려가면 유니버스에서 빠진다.
    그래서 최종 상장폐지 수익은 대부분 유니버스 밖에서 일어난다.
  - 모멘텀·저변동성·52주 고점 신호는 같은 종목을 공매도한다. 이 신호들을 섞으면 부호가 뒤집혀,
    생존 자료가 오히려 전략을 과소평가한다.

■ 3. 문헌값과 산술 대조
  - Shumway(1997): CRSP에 빠진 성과 사유 상장폐지 수익은 NYSE/AMEX에서 평균 약 −30%.
    Shumway·Warther(1999): 나스닥에서는 약 −55%. (기억에 의존한 근사값이고 이번에 원문을 확인하지 않았다.)
  - 산술: 편향(연수익) = 연간 실패 수 × 비중 0.4% × 보유 중 손실.
    검증 중 시나리오: 1개 × 0.4% × 약 50% = 0.2%p. 변동성 8.3%로 나누면 Sharpe 약 0.02로, 시뮬레이션 0.022와 맞는다.
    문헌의 상장폐지 수익(−30~−55%)을 그대로 넣어도 같은 자릿수다.

■ 4. 재지 못한 것 (판정을 해석할 때 함께 볼 것)
  1) 피인수 종목 누락. 인수 발표일의 급등이 자료에 없다. 직전에 많이 빠진 종목이 인수되는 경우가 많아
     반전 전략에는 대체로 유리한 사건이므로, 누락은 전략에 불리한 쪽이다. 크기는 재지 않았다.
  2) 대체 효과. 빠진 대형주 자리를 더 작은 생존 종목이 채운다(2003년에는 자격 종목의 상위 58%까지).
     작은 종목은 반전 수익이 더 크고 실제 거래 비용도 더 높다. 학습 구간의 비용 전 Sharpe가 부풀려지고
     10bp 가정이 낙관적일 수 있다. 이 효과는 위 편향 숫자에 들어 있지 않고, 크기도 재지 않았다.
     학습 구간에서 더 크고 검증 구간(자격 종목 1,554개 이상)에서는 작다.
  3) 실패 종목의 개수와 경로는 가정이다. 시기 집중(2008~09년)은 넣지 않고 구간 안에 고르게 뿌렸다.
  4) 대리 전략은 섹터 중립이 없고 신호가 일부뿐이다. W1 엔진의 C1~C3와 변동성이 다르면 Sharpe 편향도 비례해 달라진다.
     환산식: 편향(Sharpe) = 편향(연수익) ÷ 해당 전략의 연 변동성.
     편향(연수익)은 반전형 기준 학습 0.2 / 0.6 / 1.1%p, 검증 0.1 / 0.2 / 0.5%p다.
