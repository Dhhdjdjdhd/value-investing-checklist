7. 문제 생겼을 때
────────────────────────────────────────────────────────────────
  [증상] 접속하면 404, 헤더에 x-render-routing: no-server
   → 앱 오류가 아니라 인스턴스가 없는 상태(슬립/재시작/배포중).
     UptimeRobot 모니터가 살아있는지 먼저 확인.

  [증상] 배포는 됐는데 특정 파일만 404
   → 그 파일이 커밋됐는지 확인: git ls-files <경로>
     GitHub 웹에서도 실제로 있는지 확인.

  [증상] 빌드 실패
   → Render 로그의 npm install / npm run build 구간을 볼 것.
     로컬에서 npm run build 를 돌려 재현되는지 먼저 확인.

  [Render 강제 재배포]
   대시보드 우측 상단 Manual Deploy
   → "Clear build cache & deploy" (빌드 캐시 문제일 때)
