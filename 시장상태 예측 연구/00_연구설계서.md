# 시장 상태 예측 연구 — 연구설계서 (사전 등록)

- 작성: 2026-11-22 / 매니저: 세션 value-investing-checklist-98 / 상태: 설계 고정 → 실행
- 요청: "변동성 · 조건부 확률 · 경기침체 신호로 예측 프로세스를 만들고, 그에 따라 전략을 조정할 수 있나. 지수와 종목(조건부 확률) 둘 다." (은퇴 계획과 무관한 일반 연구)
- 원칙: 규칙과 판정 기준은 **결과를 보기 전에 고정**한다. 실행 세부(데이터 보정, 결측 처리 등)는 작업자가 결과를 보기 전에 각자 `부록 A/B/C`에 적는다. 결과를 본 뒤 바꾸거나 추가한 것은 "사후"로 표시하고, 원래 판정은 지우지 않는다.
- 출발점: 이미 탈락한 것은 다시 시험하지 않는다. 공포 때 더 사기(차트 4차 P5 탈락), CAPE로 비중 조절(대안전략 §L 탈락·보류), 차트로 방향 맞히기(차트 1~4차, 코인 롱숏 탈락)가 여기에 해당한다. 200일선 추세 규칙은 **기준선**으로만 쓴다.

## 공통 사항

| 항목 | 내용 |
|---|---|
| 학습 / 검증 | 학습 1950-01 ~ 1999-12, 검증 2000-01 ~ 2026-11 (지수). 종목은 §C 참조 |
| 수익 | 가능하면 총수익. 일간 가격 지수를 쓰면 배당을 Shiller 월간 배당으로 보충하거나 "가격 기준"이라고 명시 |
| 현금 수익 | 3개월 T-bill (FRED TB3MS, 1934~). 일간은 월값을 일할 |
| 비용 | 편도 0.1% × 비중 변화량 |
| 신호 시점 | t일 종가(또는 t월 말)에 계산하고 t+1일(또는 t+1월)부터 적용. 월간 거시 지표는 **발표 지연 1개월**을 둔다 |
| 기준선 | ① B&H(주식 100%) ② TF200(200일선 위면 100%, 아래면 현금) ③ **평균 노출 맞춤 고정 비중**: 규칙의 검증 구간 평균 주식 비중과 같은 고정 비중(매월 리밸런싱) |
| 통계 | 블록 부트스트랩(월간 12개월 블록 또는 일간 250일 블록, 1,000회). 사건 통계는 연도 군집 표준오차 |
| 다중검정 | 시험한 규칙 수를 모두 기록한다. 판정은 학습 구간 1위 규칙 하나만 검증 구간에서 판정한다(검증 성적으로 고르지 않음) |

**전략 판정 (A·B 공통, 미리 고정)**

"채택"은 학습 1위 규칙이 **검증 구간에서** 아래를 모두 만족할 때다.
1. Sharpe > B&H, Sharpe > 평균 노출 맞춤 고정 비중
2. MDD가 B&H보다 5%p 이상 개선
3. 부트스트랩(규칙 Sharpe − B&H Sharpe > 0) ≥ 0.90

1·2는 만족했는데 3이 미달이면 "보류", 나머지는 "탈락"이다.

**확률 판정 (예측력)**
- 검증 구간 브라이어 점수가 기준 확률(학습 구간 평균 빈도)보다 낮아야 "예측력 있음"이다. 보정 그림(신뢰도 도표, 5~10구간)을 함께 낸다.

## A. 변동성 예측과 변동성 목표화 (작업자 1)

**A1. 예측 모델** — 목표는 다음 21거래일 실현 변동성(연율)이다.

| 모델 | 정의 |
|---|---|
| V1 | 지난 21일 실현 변동성 |
| V2 | EWMA λ = 0.94 |
| V3 | GARCH(1,1), 확장 창으로 매년 1월 재추정 |
| V4 | VIX/100 (1990~, 참고) |

평가: 검증 구간에서 log(실현) vs log(예측)의 R²와 QLIKE 손실. 학습 1위 모델을 A2에 쓴다.

**A2. 변동성 목표화 전략**
- 주식 비중 w = min(L, σ* / σ̂). σ*는 학습 구간 S&P 실현 변동성의 평균으로 고정한다.
- 조합: L ∈ {1.0, 1.5} × 리밸런싱 {매월, 매일(비중 차이 20% 넘을 때만)} = 4개 규칙.
- L = 1.5는 레버리지 비용(T-bill + 0.5%)을 빼고 계산하며, 참고용이다. 판정은 L = 1.0 규칙 중 학습 1위로 한다.

**A3. 산출물**: `src/A_vol.py`, `results/A_forecast.csv`, `A_rules.csv`, `A_verdict.csv`, `A_summary.txt`, 현재(2026-11-20) 예측 변동성과 그에 따른 비중.

## B. 경기침체 신호와 조건부 확률표 (작업자 2)

**B1. 데이터 (FRED 공개 CSV)**
- 10년물 − 3개월물 금리차: GS10 − TB3MS(1953~)
- 실시간 삼 규칙(SAHMREALTIME). 없는 기간은 UNRATE로 계산하고 "수정값"이라고 표시
- 신용 스프레드: BAA − AAA (1919~)
- 경기침체 구간: USREC

**B2. 경기침체 확률 모델** (목표: 향후 12개월 안에 경기침체 시작 또는 진행)

| 모델 | 정의 |
|---|---|
| R1 | 금리차 probit (Estrella–Mishkin) |
| R2 | 삼 규칙 ≥ 0.5 |
| R3 | 금리차 + 신용 스프레드 6개월 변화 probit |

추정은 확장 창으로 매년 재추정한다. 평가는 검증 구간 브라이어 점수와 AUC다.

**B3. 침체 신호 전략**
- 평소 주식 100%, 신호가 켜지면 주식 50%.
- 신호: R1 확률 > 0.5 / R2 발동 / R3 확률 > 0.5 / R1 또는 R2 → 4개 규칙.
- 공통 판정 기준을 적용한다.

**B4. 조건부 확률표 (S&P)**
- 상태 변수
  - 변동성 국면: V2 기준 학습 구간 3분위
  - 낙폭 구간: 0 ~ −5 / −5 ~ −10 / −10 ~ −20 / −20% 이하
  - 200일선 위·아래
  - R1 침체 확률 높음(> 0.3) / 낮음
- 칸마다 내는 값
  - 1·3·12개월 뒤 수익 분포(10·50·90 분위)
  - 12개월 안 추가 −10% 확률, 12개월 안 −20%(고점 대비) 도달 확률
  - 사건 수와 연도 수
- 표본이 연도 5개 미만인 칸은 "참고"로 표시한다.
- **보정 검증**: 학습 구간 표로 검증 구간을 예측해 브라이어 점수를 기준 확률과 비교한다.

**B5. 산출물**: `src/B_macro.py`, `data/fred_*.csv`, `results/B_models.csv`, `B_rules.csv`, `B_verdict.csv`, `B_table.csv`, `B_calibration.csv`, `B_summary.txt`, 현재 상태 판독표(2026-11-20).

## C. 종목별 조건부 확률: 큰 하락 뒤 회복 (작업자 3)

**C1. 데이터**: `체크리스트 검증/data`의 미국 종목 주가(분할 보정)와 SEC 최초 공시 재무 패널. 먼저 **상장폐지 종목이 얼마나 포함됐는지** 측정한다. SEC 기업 중 주가가 없는 비율과, 마지막 가격이 2026년 이전에 끝나는 종목 수를 본다.

**C2. 사건 정의**
- 종목 종가가 직전 고점(상장 후 최고가, 배당 제외 가격) 대비 −30%, −50%를 처음 넘은 날.
- 직전 고점을 회복하면 다시 사건이 될 수 있다.
- 사건일 기준 시가총액 10억 달러 이상만 대상으로 한다.

**C3. 조건 변수 (사건일 시점 정보만)**
- Q: 체크리스트 v2 품질 관문 통과 여부. 그 시점까지 공시된 10-K만 쓴다.
- M: 시장 동반 하락 여부. S&P가 고점 대비 −15% 이하면 "시장형", 아니면 "개별형".
- S: 경기순환 섹터 여부. 체크리스트 기준을 따른다.

**C4. 결과 변수**
- 직전 고점 회복 확률: 1·3·5년 안
- 12·36개월 수익과 S&P 대비 초과수익
- 사건일 이후 추가로 −30% 더 빠질 확률
- 상장폐지 또는 가격 소멸: "회복 실패, 마지막 가격으로 청산"으로 처리한다.

**C5. 구간**: 학습은 2006 ~ 2015년 사건, 검증은 2016 ~ 2021년 사건이다(5년 추적을 위해). 2022~2026년 사건은 1년 결과만 참고로 낸다.

**C6. 판정 (미리 고정)**
- "유용한 조건"은 Q 통과와 실패의 3년 회복 확률 차이가 학습과 검증 **모두** 10%p 이상이고, 기업 군집 부트스트랩 90% 구간이 0을 넘지 않을 때다.
- M, S도 같은 기준으로 본다.
- 생존편향 보정: 주가가 없는 SEC 기업을 "전부 회복 실패"로 넣은 하한을 함께 보고한다.

**C7. 참고 사례 (판정 외)**: 삼성전자(1990~)의 −30%·−50% 사건과 회복 일수. 데이터는 `대안전략 연구/data/y_005930.KS_adj.csv`다. 현재 상태 예시로 NVDA, ANT(데이터 부족 시 생략)도 넣는다.

**C8. 산출물**: `src/C_stock.py`, `results/C_events.csv`, `C_table.csv`, `C_verdict.csv`, `C_survivorship.txt`, `C_summary.txt`.

## 작업 규칙 (모든 작업자)

- 폴더: `E:/value-investing-checklist/시장상태 예측 연구/` 아래 `src/`, `data/`, `results/`. 파일명은 접두사 A_/B_/C_로 나눈다. 다른 작업자 파일은 건드리지 않는다.
- 실행: `py -I`. 기존 연구 코드는 경로를 추가해 불러오되 고치지 않는다.
- 외부 요청: User-Agent는 `Mozilla/5.0 (compatible; research-script)`. **이메일 주소나 개인정보를 요청에 넣지 않는다.**
- 하지 않는 것: git commit/push, 메일 발송, 모니터 설정 변경, 외부 게시. 이런 것은 매니저가 한다.
- 엔진 검증: 룩어헤드 점검(데이터를 자른 뒤 다시 계산한 신호가 같아야 함)과 B&H 재현을 각 작업자가 한다.
- 완료 보고: 매니저 세션에 결과 요약(판정, 핵심 숫자 5~10개, 한계, 파일 목록)을 보낸다. 막히면 스스로 합리적으로 판단해 진행하고, 판단한 내용을 부록에 적는다.
